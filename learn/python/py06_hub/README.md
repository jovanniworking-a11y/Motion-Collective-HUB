# py06 · Read hub.py and add one field
Reading real code is the skill that makes everything else possible.

1. Open `hub.py`. Write down (in this file, under "My notes") what each top-level function does, in one line each.
2. Find where an event is described (its fields). Add a new field, `camera_count`, with a default of 5.
3. Run `python hub.py` and check the Excel export has the new column.
4. Commit it on a branch: `git switch -c learn/py06`, `git add hub.py`, `git commit -m "hub: camera_count field"`.

There's no automatic check here. Ask Claude Code: "review my py06 change, explain anything I got wrong, don't fix it."
