# Motion Collective HUB

This initial code package contains the latest complete MOTION web app found locally: the CH31 production planner last edited on September 21, 2026. It was copied from the original Codex project without changing that source. Creative scripts, flyers, music, cap designs, and planning spreadsheets remain in the separate consolidated archive.

## What the app does

The private planner covers workflow, equipment and purchases, budget, crew/run of show, and research for the October 30, 2026 event. See `PRODUCT.md` and `DESIGN.md` for the source brief.

## Run locally

Requires Node.js 22.13 or newer. Install with `npm ci`, then run `npm run dev`. This code came from a Sites/vinext starter, so deployment configuration and authentication should be reviewed for the target host before publishing. No live credentials are included.
